# 💼 Job Application Tracker + AI Resume Fit (MERN Stack)

A full-stack MERN (MongoDB, Express, React, Node.js) web app to help job seekers track their job applications and get AI-powered feedback on how well their resume fits a job description.

---

## 🚀 Features

- 🧑‍💼 User Authentication (Register, Login, Logout)
- 📋 Add, edit, and delete job applications
- 📊 Track status (saved, applied, interview, rejected, offer)
- 📅 View date applied and job descriptions
- ✏️ Edit job details any time
- 🗑️ Delete entries with confirmation
- 🧠 **Coming Soon**: AI Resume Fit Analysis using OpenAI/Gemini API
